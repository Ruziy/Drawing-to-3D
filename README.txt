DRAWING-TO-3D — ПОЛЬЗОВАТЕЛЬСКИЙ БИЛД ДЛЯ WINDOWS x64

Внутри только приложение, INSTALL.ps1, START.ps1 и эта инструкция.
Нет тестов, примеров чертежей, отчётов, старых CAD-результатов,
скриптов разработчика, CMD-файлов, готовых окружений и весов LLM.
application/app — исполняемая логика программы, а не лишние файлы.
application/static — интерфейс, 3D-библиотека и её лицензия.
application/requirements.txt — список устанавливаемых Python-библиотек.

1. Распакуйте ZIP, например в C:\Drawing3D. Откройте PowerShell в этой папке.
   Нужны интернет, Windows x64 и WinGet (Microsoft App Installer).

2. ОДНА КОМАНДА УСТАНОВКИ с выбранной вами локальной vision-моделью:

   powershell -NoProfile -ExecutionPolicy Bypass -File .\INSTALL.ps1 -Model qwen3.5:9b

   Вместо qwen3.5:9b можно указать gemma4:12b, qwen3-vl:4b
   или другой точный установленный/доступный локальный vision-тег Ollama.
   Несколько моделей: -Model "qwen3.5:9b,gemma4:12b"
   Без LLM: -WithoutLLM вместо -Model.
   Если запустить INSTALL.ps1 без параметров, он спросит нужные теги.
   Пустой ответ означает режим CV/OCR без установки Ollama и её весов.
   Только показать план, ничего не скачивая: добавить -Plan.

   Скрипт устанавливает отсутствующие uv, Tesseract, Python 3.11,
   Python-зависимости, OCR-данные eng/rus, FreeCAD 1.1.4.
   Для распаковки FreeCAD используется 7-Zip, при отсутствии он устанавливается
   автоматически. Системный tar.exe не требуется: не все его версии читают LZMA.
   При выборе LLM дополнительно устанавливает/запускает Ollama,
   скачивает только выбранные модели и проверяет поддержку изображений.
   Уже установленные Ollama-модели повторно не скачиваются.
   Windows может запросить подтверждение установки системных программ.
   При ошибке установка останавливается с объяснением; запускать START
   следует после сообщения Installed successfully.
   Если предыдущая установка прервалась на распаковке, замените INSTALL.ps1
   исправленной версией и повторите ту же команду в прежней папке.
   Проверенный archive application/.runtime/FreeCAD.7z используется повторно,
   существующие .venv и OCR-данные сохраняются, неполная распаковка исправляется.

3. ЗАПУСК:

   powershell -NoProfile -ExecutionPolicy Bypass -File .\START.ps1

   Откройте http://127.0.0.1:8000 в браузере. Загружайте собственный PDF,
   выбирайте модель и нажимайте «Анализировать и построить 3D».
   Если порт занят, добавьте -Port 8001. Остановка — Ctrl+C в терминале.
   Для принудительного CV/OCR можно добавить -Classic.

4. ДОБАВИТЬ ИЛИ СМЕНИТЬ LLM:

   Повторите INSTALL.ps1 с другим -Model. Он добавит выбранную модель,
   не удаляя предыдущие; первой моделью из списка задаётся новый default.
   Либо выполните ollama pull <точный тег> и «Обновить модели» в интерфейсе.
   Для гибридного режима Ollama должна оставаться запущенной.
   Конфигурация — application/.env этой распакованной папки.

ПОСЛЕ УСТАНОВКИ

Папка увеличится: Python, библиотеки, OCR и FreeCAD сохраняются внутри
application/.venv, application/.runtime и application/.cache.
LLM-веса — в каталоге Ollama пользователя, обычно %USERPROFILE%\.ollama\models.
Новая обработка PDF — в application/data. Они создаются при работе,
а в исходный ZIP не включены. Устанавливать все модели не требуется.
Для крупных моделей нужна достаточная RAM/VRAM; на CPU работа медленнее.

РЕЗУЛЬТАТЫ

STEP/FCStd — CAD, STL — сетка. JSON-ссылки объясняют извлечённые данные,
интерпретацию, план построения и проверки. B означает частичную CAD,
C — предварительную с оценками, D — приблизительную сетку.
Успешный экспорт не гарантирует полного совпадения с чертежом.
В этом чистом билде нет сохранённых кандидатов из прежних тестов:
новые PDF обрабатываются с нуля, поэтому исторические показатели с
повторным использованием сохранённых B нельзя приписывать этому билду.

Полная сетевая установка на чистом физическом компьютере пока не проверялась.
Синтаксис/план установки и работа самого приложения проверяются отдельно.
